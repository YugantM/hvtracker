Is DeerFlow safe?

DeerFlow has a mixed signal profile. Some trust indicators are present, others are missing. Whether it is safe for your use case depends on which gaps matter to you — review the breakdown below before adopting in production.
Does DeerFlow publish package provenance?
No published build provenance is currently detected for DeerFlow. This is common for open-source projects but means consumers cannot independently verify that the package on the registry matches the GitHub source.
Does DeerFlow have an OpenSSF Scorecard?
DeerFlow has an OpenSSF Scorecard score of 7.1/10. The Scorecard checks for branch protection, signed releases, dependency updates, fuzzing, code review, and other supply-chain hygiene items. See the full check breakdown on this page.
Is DeerFlow actively maintained?
Actively maintained. The repository was pushed to within the last 1 day(s).
What license does DeerFlow use?
DeerFlow ships under MIT. A declared, OSI-approved license is one of the transparency signals HVTrust scores.
Are DeerFlow's commits signed?
100% of the last 100 commits to DeerFlow are verified-signed (GPG, SSH, S/MIME, or GitHub's signing flow). Signed commits help confirm that code was authored by who the commit claims.

Not a safety endorsement. HVTracker describes what public signals show, not whether a project is safe for your use case. Run your own security review before adopting in production.
