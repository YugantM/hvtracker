Is LibreChat safe?

LibreChat has a mixed signal profile. Some trust indicators are present, others are missing. Whether it is safe for your use case depends on which gaps matter to you — review the breakdown below before adopting in production.

No published build provenance is currently detected for LibreChat. This is common for open-source projects but means consumers cannot independently verify that the package on the registry matches the GitHub source.
