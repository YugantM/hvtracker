# HVTracker — Logo Design Brief

**Paste this into Recraft / Ideogram / a Fiverr designer.**

## What we are
HVTracker is an independent **trust registry for AI agents** — we score 192 open-source
and proprietary AI tools on supply-chain trust (security, provenance, transparency).
Audience: software developers, security engineers, AI researchers. Tone: credible,
technical, calm authority. Not playful, not corporate-generic.

## Concept: "Hawk View"
"HV" = **Hawk View** — sharp oversight, vigilance, spotting what others miss. The mark
should evoke *keen watchfulness / precision tracking*, not a literal cartoon bird.
Good metaphors: a hawk's eye, a sharp angular raptor silhouette, a focus/scope reticle,
a precise sightline. Avoid generic "eye" icons that look like a show/hide-password toggle.

## Style
- **Minimalist, geometric, monoline or simple solid shapes.** Single strong idea.
- Must work as a **favicon at 16×16** (no fine detail that disappears when small).
- Flat / vector. No gradients-heavy, no 3D, no mascots, no drop shadows.
- Modern tech-brand feel (think Linear, Vercel, Raycast logo simplicity).

## Colors (brand palette — use these exact hex)
- Teal (primary):       `#2dd4bf`
- Amber (secondary):    `#d8a657`
- Periwinkle (accent):  `#8fb3ff`
- Near-black background: `#0b0d10`
- Off-white:            `#eef2f6`
Prefer 1–2 colors in the mark. It must read on **both dark (#0b0d10) and light (#eef2f6)**.

## Wordmark
Text: **HVTracker**, styled as "HV" + "Tracker" (two weights/colors is fine, e.g. HV in
white/teal, "Tracker" in periwinkle `#8fb3ff`). Optional tagline: *"Hawk View on AI agent trust."*
Clean geometric sans (Inter, Geist, or similar).

## Deliverables
1. Icon mark — **SVG**, transparent background.
2. Favicon version that's legible at 16/32 px.
3. Horizontal lockup (icon + "HVTracker" wordmark).
4. App-icon tile (mark centered on a `#0b0d10` rounded square).
5. Optional: 1200×630 OG/social image using the mark + tagline.
